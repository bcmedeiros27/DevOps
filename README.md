I wll be creating an interactive website with a reflex test game. A button will appear that is red and when it turns green the user clicks on it. Time for the user to click the button is recorded. After that the player may chose to upload their name and score to a leaderboard. Scores will be saved to a database and displayed on the leaderboard. 
# Front End
The front end will use React and JS to display the test, scores, results and leaderboards
# Backend
Backend will use ASP.NET and C# to recive and validate the scores, and return leaderboard results.
